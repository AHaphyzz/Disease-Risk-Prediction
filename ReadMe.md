# Disease Risk Prediction from Physiological Data 🧬

This project analyzes synthetic patient data to identify how physiological and lifestyle factors correlate with disease risk. The analysis was conducted using Python in Google Colab.

## 📁 Dataset
A synthetic CSV file named `synthetic_patient_data_v2.csv` was generated containing:
- Age
- Gender
- Blood Pressure
- BMI
- Cholesterol Level
- Smoking Status
- Physical Activity Level
- Family History
- Disease Risk (Low, Medium, High)

## 🧪 Project Objectives
- Explore the distribution and relationship between patient features and disease risk.
- Visualize key statistics and patterns.
- Build a classification model to predict disease risk based on patient data.

## 🔧 Tools Used
- Python (Pandas, NumPy)
- Seaborn & Matplotlib (Data visualization)
- Scikit-learn (Machine Learning)

## 📈 Analysis Steps
1. **Data Exploration**: Checked missing values, summary statistics, and visualized distributions.
2. **Feature Engineering**: Encoded categorical features and the target variable.
3. **Model Training**: Used a Random Forest Classifier to model disease risk.
4. **Evaluation**: Evaluated model performance using a classification report.

## 🧠 Results
The model effectively categorized patients into Low, Medium, or High disease risk using physiological markers and lifestyle indicators.

## 📎 How to Run
1. Upload `synthetic_patient_data_v2.csv` to your Google Colab environment.
2. Run all cells in the provided notebook.
3. View data visualizations and model performance output.
